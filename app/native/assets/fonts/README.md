# Editor emphasis fonts

Unmodified static Roboto Bold, Italic, and BoldItalic from
https://github.com/googlefonts/roboto-2/tree/main/src/hinted.

These faces supplement iced-m3's variable Roboto font because the native text
renderer otherwise falls back to a system font for bold and italic spans.
The upstream Apache 2.0 license is in `../../licenses/roboto-static/LICENSE`
and ships with native packages.

FiraMono-Medium.ttf is the unmodified font bundled with cosmic-text 0.15.0.
It renders inline and fenced code consistently. Its SIL Open Font License is
in `../../licenses/fira-mono/LICENSE`.
